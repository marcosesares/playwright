## Glossary

| Term | Definition | Confidence |
|------|-----------|-----------|
| **BrowserType** | One of `chromium`, `firefox`, `webkit` — the entry point for launching or connecting to a browser instance. | 🟢 CONFIRMADO |
| **BrowserContext** | An isolated browser session with its own cookies, storage, and permissions. Multiple contexts can share a single Browser. | 🟢 CONFIRMADO |
| **Page** | A single browser tab. Belongs to exactly one BrowserContext. | 🟢 CONFIRMADO |
| **Frame** | A browsing context within a page — either the main frame or an iframe. Pages always have at least one main frame. | 🟢 CONFIRMADO |
| **Locator** | A lazy, auto-retrying reference to one or more DOM elements. Deferred — does not resolve until an action is performed. | 🟢 CONFIRMADO |
| **ElementHandle** | A live reference to a single DOM element, pinned at creation time. Unlike Locator, it does not auto-retry. | 🟢 CONFIRMADO |
| **ChannelOwner** | Abstract base class for all public client API objects. Wraps a Proxy that routes method calls through the RPC protocol. | 🟢 CONFIRMADO |
| **SdkObject** | Abstract base class for all server-side objects. Carries `guid`, `attribution`, and `instrumentation`. | 🟢 CONFIRMADO |
| **Dispatcher** | Server-side RPC bridge that wraps an SdkObject and exposes it over the wire protocol to the client. | 🟢 CONFIRMADO |
| **Protocol** | The YAML-defined contract (`packages/protocol/spec/*.yml`) that specifies all channels, commands, and events between client and server. | 🟢 CONFIRMADO |
| **Route** | An intercepted network request that can be fulfilled, aborted, or passed through. | 🟢 CONFIRMADO |
| **Tracing** | Recording of browser actions, snapshots, and network activity into a `.zip` trace file. | 🟢 CONFIRMADO |
| **HAR** | HTTP Archive format — a structured log of network interactions. Playwright can record and replay HAR files. | 🟢 CONFIRMADO |
| **MCP** | Model Context Protocol — exposes Playwright browser automation as AI-callable tools over a JSON-RPC-like protocol. | 🟢 CONFIRMADO |
| **ToolCapability** | A named group of MCP tools. Enables/disables subsets of functionality: `core`, `vision`, `pdf`, `devtools`, etc. | 🟢 CONFIRMADO |
| **ApiZone** | Per-call tracing context capturing the API name, user call stack, step ID, and result. Used to build trace files. | 🟢 CONFIRMADO |
| **Progress / ProgressController** | Timeout-aware operation tracking. Wraps async operations to enforce deadlines and propagate cancellation. | 🟢 CONFIRMADO |
| **GC Bucket** | Mechanism to evict oldest dispatchers when per-type object counts exceed a threshold (10,000 general; 100,000 for handles). | 🟢 CONFIRMADO |
| **Attribution** | Chain of parent objects attached to every SdkObject: `playwright → browserType → browser → context → page → frame`. | 🟢 CONFIRMADO |
| **Actionability** | Set of element state preconditions that must be satisfied before an interaction (click, fill, etc.) is performed. | 🟢 CONFIRMADO |
| **Snapshot** | A serialized DOM + CSS state captured by the trace recorder for offline replay in the trace viewer. | 🟡 INFERIDO |
| **InjectedScript** | TypeScript bundled and injected into the browser page at runtime. Runs in the page's JS context (no Node.js APIs). | 🟢 CONFIRMADO |
| **DEPS.list** | Import boundary enforcement file. Declares which packages a module may import. Enforced by `npm run flint`. | 🟢 CONFIRMADO |
| **Extension Protocol** | Versioned protocol (v1/v2) for the Chrome extension ↔ Playwright CDP relay used in MCP extension mode. | 🟢 CONFIRMADO |

## Business Rules

### BR-01 — Actionability Checks (Pre-Interaction)
🟢 CONFIRMADO — `packages/injected/src/injectedScript.ts:653`, `packages/playwright-core/src/server/dom.ts:316`

Before executing any user-visible interaction (click, fill, select, dblclick, tap, drop), the element must satisfy a set of preconditions depending on the action:

| Action | Required States |
|--------|----------------|
| Click, dblclick, tap | `visible`, `stable`, `enabled` |
| Fill | `visible`, `stable`, `enabled`, `editable` |
| Select text | `visible`, `stable` |
| Hover | `stable` |
| Scroll into view | `stable` |

Playwright retries the action with progressive back-off until conditions are met or the timeout expires. Retry wait times: `[100, 250, 500]` ms, capped at 500 ms.

### BR-02 — Event Subscription Reference Counting
🟢 CONFIRMADO — `packages/playwright-core/src/client/channelOwner.ts:76-109`

Protocol-level events are lazily enabled and eagerly disabled:
- First listener added → send `updateSubscription` command to server (enable)
- Last listener removed → send `updateSubscription` command to server (disable)

This prevents unnecessary protocol traffic for events no user code is listening to.

---

### BR-03 — Locator Frame Boundary
🟢 CONFIRMADO — `packages/playwright-core/src/client/locator.ts:56-64`

`has` and `hasNot` locators used in filter operations **must belong to the same frame** as the outer locator. Violating this throws an Error immediately (no retry).

---

### BR-04 — MCP Output Directory Protection
🟢 CONFIRMADO — `packages/playwright-core/src/tools/mcp/config.ts:139`

The `--output-dir` option for the MCP server cannot point to a system directory. `isSystemDirectory()` check runs at config resolution time. Throws immediately if violated.

---

### BR-05 — Isolated Mode Prohibits userDataDir
🟢 CONFIRMADO — `packages/playwright-core/src/tools/mcp/config.ts`

When `--isolated` is set (ephemeral context per session), `--userDataDir` is prohibited and throws an Error. These two options are mutually exclusive by design.

---

### BR-06 — Headless Default on Linux Without Display
🟢 CONFIRMADO — `packages/playwright-core/src/tools/mcp/config.ts`

`headless` defaults to `true` when `os.platform() === 'linux'` and `process.env.DISPLAY` is not set. Otherwise defaults to `false`.

---

### BR-07 — Chromium AutomationControlled Flag
🟢 CONFIRMADO — `packages/playwright-core/src/tools/mcp/config.ts`

`--disable-blink-features=AutomationControlled` is injected for Chromium by default to prevent bot detection. This is a behavioral decision affecting test realism.

---

### BR-08 — Sandbox vs No-Sandbox
🟢 CONFIRMADO — `packages/playwright-core/src/tools/mcp/config.ts`

An explicit `--sandbox` or `--no-sandbox` flag overrides the platform default. Without explicit flag, sandbox behavior follows OS defaults (typically disabled on Linux CI).

---

### BR-09 — Config Path Resolution
🟢 CONFIRMADO — `packages/playwright-core/src/tools/mcp/config.ts`

`initPage` and `initScript` paths are resolved relative to the config file's directory, **not** the current working directory. This prevents ambiguity when config files are in a non-root location.

---

### BR-10 — GC Bucket Object Limits
🟢 CONFIRMADO — `packages/playwright-core/src/server/dispatchers/dispatcher.ts:41-51`

When the number of live dispatcher objects in a bucket exceeds the threshold, the oldest are garbage-collected and the client is notified:

| Bucket | Limit |
|--------|-------|
| `JSHandle`, `ElementHandle` | 100,000 |
| All other types | 10,000 |

---

### BR-11 — File Upload Colocation Requirement
🟢 CONFIRMADO — `fix(fileUpload): reject localPaths when client is not collocated with server (#41080)`

`localPaths` parameter for file uploads is rejected when the client process is not running on the same machine as the browser server. Throws a clear error rather than silently failing.

---

### BR-12 — Client-Certificate TLS Scope
🟢 CONFIRMADO — `fix(client-certificates): do not intercept TLS for non-matching origins (#41113)`

Client certificates only intercept TLS connections for their declared origin(s). Non-matching origins pass through without interception.

---

### BR-13 — Cookie Mutation Isolation
🟢 CONFIRMADO — `fix(server): clearCookies({name}) should not transiently delete other cookies (#40955)`

`clearCookies({ name })` must only delete cookies matching the filter. Transient deletion of unrelated cookies (then re-add) is explicitly prohibited — was a bug that was fixed.

---

### BR-14 — Test Result Outcome Classification
🟢 CONFIRMADO — `packages/playwright/types/testReporter.d.ts:291`

A test result's `outcome` is computed from `expectedStatus` vs actual `status`:

| Actual | Expected | Outcome |
|--------|----------|---------|
| any | any (test.skip) | `skipped` |
| same as expected | — | `expected` |
| different from expected | — | `unexpected` |
| passed on retry after failing | — | `flaky` |

---

### BR-15 — Protocol YAML as Source of Truth
🟢 CONFIRMADO — `packages/protocol/spec/`

The protocol YAML files are the source of truth for all client↔server communication. TypeScript types (`channels.d.ts`) and validators are generated from them. Manual edits to generated files are overwritten by `npm run watch`.

---

### BR-16 — Non-Collocated Download Save
🟢 CONFIRMADO — `fix(download): clear error when saving downloads from a non-collocated browser (#41088)`

Saving a download to a local path from a browser running on a remote server requires explicit handling. A clear error (not a silent hang) is thrown when the save path is not accessible from the browser's host.

## Implicit Business Decisions

| Decision | Evidence | Confidence |
|----------|----------|-----------|
| `toJSON()` on any public API object returns only `{_type, _guid}` | Prevents circular reference crashes in Jest/console output | 🟡 INFERIDO |
| Attribution chain is shallow-cloned from parent | Avoids circular references while preserving full context | 🟡 INFERIDO |
| `debugLogger` is the single logging sink with named channels | Centralized; channels: `api`, `browser`, `protocol`, `error` | 🟢 CONFIRMADO |
| `networkidle` lifecycle is excluded from `RegularLifecycleEvent` | Special handling — not used in standard wait sequences | 🟢 CONFIRMADO — `frames.ts:69` |
| Electron API was moved to separate package then reverted | Stability/release concerns during stabilization period | 🟡 INFERIDO from reverts #40184, #40733 |
