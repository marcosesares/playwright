## Overview

Playwright is an open-source browser automation monorepo (Microsoft, Apache-2.0) at version `1.61.0-next`. It provides a cross-browser automation library, a self-hosted test runner, an MCP server for AI-agent integration, and a suite of React-based tooling UIs.

**Core architectural pattern:** Client/Server split over a contract-first YAML RPC protocol. Users interact with a thin client API (`ChannelOwner` hierarchy); all actual browser control runs in a separate server process that communicates through a typed WebSocket-like channel.

## RPC Communication Flow

```
User Code
  │  calls e.g. page.click('#btn')
  ▼
ChannelOwner._wrapApiCall()      ← captures stack trace, creates ApiZone
  │
  ▼
Proxy._createChannel()           ← validates params, serializes call
  │  WebSocket / in-process pipe
  ▼
DispatcherConnection.dispatch()  ← receives message, looks up Dispatcher by GUID
  │
  ▼
PageDispatcher.click()           ← unmarshals params, calls server method
  │
  ▼
SdkObject (Page server)          ← executes browser command via CDP/Juggler/WebKit protocol
  │
  ▼
Browser Process (Chromium/Firefox/WebKit)
```

## Object Lifecycle

Each public API object has a symmetric pair:

| Client (ChannelOwner) | GUID | Server (SdkObject) | Dispatcher |
|-----------------------|------|--------------------|-----------|
| `Page` | `page@uuid` | `Page` (server) | `PageDispatcher` |
| `Frame` | `frame@uuid` | `Frame` (server) | `FrameDispatcher` |
| `BrowserContext` | `browser-context@uuid` | `BrowserContext` (server) | `BrowserContextDispatcher` |
| `Browser` | `browser@uuid` | `Browser` (server) | `BrowserDispatcher` |
| `BrowserType` | `browser-type@uuid` | `BrowserType` (server) | `BrowserTypeDispatcher` |
| `ElementHandle` | `element-handle@uuid` | `ElementHandle` (server) | `ElementHandlerDispatcher` |

Object disposal: client calls `_dispose()` → sends protocol message → dispatcher removed from connection → `SdkObject` closed.

GC fallback: when a bucket exceeds its limit (10k general, 100k handles), oldest dispatchers are evicted automatically.

🟢 CONFIRMADO — `channelOwner.ts:117`, `dispatcher.ts:41-51`
