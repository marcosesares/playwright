## Protocol Architecture

The project uses a custom RPC protocol:
- **Source:** YAML spec files in `packages/protocol/spec/` (19 YAML files covering: api, android, artifact, browser, browserContext, browserType, core, electron, frame, handles, localUtils, mixins, network, page, playwright, serialized, structs, tracing, worker)
- **Generated:** `packages/protocol/src/channels.d.ts` — TypeScript channel interfaces
- **Dispatchers:** `packages/playwright-core/src/server/dispatchers/` — bridge server-side SdkObjects to client
- **Client:** `packages/playwright-core/src/client/` — ChannelOwner subclasses that call through the protocol

## MCP (Model Context Protocol)

Playwright ships an MCP server (`packages/playwright-core/src/tools/mcp/`) that exposes browser automation as tools consumable by AI agents. Entry point: `packages/playwright-core/src/entry/mcp.ts`.

Key files: `browserFactory.ts`, `browserModel.ts`, `cdpRelay.ts`, `config.ts`
